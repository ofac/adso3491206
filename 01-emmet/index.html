01-Emmet

Plugin for faster HTML and CSS coding.

01-Child: >
Creates child elements (nesting).

Example:

ul>li>a ↔️

Result:

<ul> <li> <a href=""></a> </li> </ul>

02-Sibling: +
Creates sibling elements.

Example:

section+header+nav ↔️

Result:

<section></section> <header></header> <nav></nav>

03-Multiplication: *
Repeats elements multiple times.

Example:

ul>li*3 ↔️

Result:

<ul> <li></li> <li></li> <li></li> </ul>

04-Class: .
Creates a class attribute.

Example:

menu.mainmenu ↔️

.container ↔️

Result:

<menu class="mainmenu"></menu></menu> <div class="container"></div>

05-Classes: ...
Creates multiple class attributes.

Example:

menu.mainmenu.uppercase.blue ↔️

Result:

<menu class="mainmenu uppercase blue"></menu>

06-Identification: #
Creates an ID attribute.

Example:

nav#navigation123 ↔️

Result:

<nav id="navigation123"></nav>

07-Text: {}
Inserts text content.

Example:

p{Lorem Ipsum Dolor.} ↔️

a{Click Here} ↔️

Result:

<p>Lorem Ipsum Dolor.</p> <a href="">Click Here</a>

08-Custom Attribute: []
Creates custom attributes.

Example:

a[href=www.youtube.com] ↔️

Result:

<a href="www.youtube.com"></a>

09-Item Numbering: $
Adds consecutive numbers.

Example:

ul>li.item$*5 ↔️

Result:

<ul> <li class="item1"></li> <li class="item2"></li> <li class="item3"></li> <li class="item4"></li> <li class="item5"></li> </ul>

10-Reverse Numbering: @-
Inverts numbering order.

Example:

ul>li.item$@-*5 ↔️

Result:

<ul> <li class="item5"></li> <li class="item4"></li> <li class="item3"></li> <li class="item2"></li> <li class="item1"></li> </ul>

11-Base Numbering: @n
Defines a base number for sequences.

Example:

ul>li.item$@5*5 ↔️

Result:

<ul> <li class="item5"></li> <li class="item6"></li> <li class="item7"></li> <li class="item8"></li> <li class="item9"></li> </ul>

12-Climb Up: ^
Moves up one level.

Example:

section>article>p^div.level ↔️

Result:

<section> <article> <p></p> </article> <div class="level"></div> </section>

13-Grouping: ()
Groups elements together.

Example:

(header>nav)+(section>article) ↔️

Result:

<header> <nav></nav> </header> <section> <article></article> </section>

14-Lorem: lorem
Generates placeholder text.

Example:

lorem ↔️

lorem5 ↔️

lorem*5 ↔️

Result:

Lorem ipsum dolor sit amet.

15-HTML Documents
Creates various HTML document types.

Example:

! ↔️

html:5 ↔️

Result:

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport"> <title>Document</title> </head> </html>

16-Meta Tags
Generates meta tags.

Example:

meta:vp ↔️

meta:utf ↔️

Result:

<meta name="viewport"> <meta http-equiv="Content-Type">
